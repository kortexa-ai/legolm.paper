# The Lookout and the Captain

[Published PDF](https://research.kortexa.ai/papers/lookout-captain/2026-09-07-b19d336f25c5.pdf) · [LaTeX source archive](https://research.kortexa.ai/papers/lookout-captain/2026-09-07-49f5b8662061-source.zip)

The September 7, 2026 revision uses the completed photographic, stream,
and rendered-scene experiments on 450M, 3B, and 27B frozen vision-language
models. It separates action conditioning, detector error, invocation
savings, and task correctness, and includes the August 27 follow-ups.

The independent [reproduction package](../reproductions/lookout-captain/)
contains the saved evidence, analysis, manuscript renderer, and exact
model-experiment commands. It uses the same main branch as the other papers.
Edit its paper/main.template.tex and regenerate this export.

The [release manifest](release.json) records the PDF, source, analysis,
evidence, environment, and harness identities. To compile only the paper,
unpack source.zip and follow its README.txt.
