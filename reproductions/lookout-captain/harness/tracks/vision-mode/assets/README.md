# Vision-mode assets

## HSR0081-Body-004 LOD2

The rung 3b harness downloads the `HSR0081-Body-004` LOD2 photoscan from the
Digital Reality Lab **HSRD-100** dataset at run time. The downloaded archive and
extracted mesh stay in the gitignored checkpoints tree.

- Creator: Digital Reality Lab
- Source: [HSRD-100](https://huggingface.co/datasets/digitalrealitylab/HSRD-100)
- Asset: `HSR0081-Body-004-Scan-LOD2.zip`
- License: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- Archive SHA-256: `71afed0be980a1c9343f7ea034256f824a5a1efe6998539e98ae7922c9dca67e`

The asset is used unchanged as a textured human mesh except for scene placement
and yaw performed by MuJoCo at render time.
